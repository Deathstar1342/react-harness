## Limits and review gates

Coordinator review/integration remains required. Native Linux/PTY checks are not established by Windows or browser checks; branch/integration CI should validate the final code. Browser checks are focused desktop Chrome evidence, not full mobile/screen-reader/human acceptance. No live-provider acceptance is implied.

All symlinks/junctions and mounted/special entries fail disk deletion closed; users can remove only the registration and manage those files externally. The server coordinates a single backend instance and tracked work. It cannot atomically exclude arbitrary external pathname replacement, external writers, detached processes or another backend instance. Revalidation reduces these risks but is not OS-level confinement. Large synchronous filesystem operations may temporarily delay requests. Disk effects and SQLite commits are not one transaction; recoverable partial outcomes are explicitly retained. Deletion is permanent, not a recycle-bin operation.
