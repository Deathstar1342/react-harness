Selected immutable snapshots/provenance remain outside summaries. Guidance selection does not create human authorization, original assignment provenance or verification. Personal promotion has fixed destination, exact source/resource/destination versions, shared project/personal serialization and durable pre-effect claims. Partial/result-COMMIT failures remain unknown with retained files; no automatic rollback, retry, cleanup or reconciliation. Unknown claims link exact evidence into goal uncertainty, survive later goal creation/revision, and block completion/removal. Direct Store deletion guards and exact preview ownership cleanup prevent orphan restart failures.

Stale guidance invalidates acceptance, pauses work and stops owned processes without resetting budgets or uncertainty. Executed save results settle before a selected-skill freshness stop. Human invocation pauses/drains and does not resume; native invocation only selects guidance within the existing loop. Original human messages and assignment scope stay separate.

App dirty state aggregates independent file/skill sources, including unsaved draft fields and synchronous desktop notifications. File editor manual saves remain available in planning as existing human intent; specialized skill save/promotion and model writes remain execution-only. Async panel loads abort on unmount.
