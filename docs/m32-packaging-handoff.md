The new source payload has a complete SHA256 inventory and provenance for the exact source, controller/worker images, locked dependency graph, target Electron and private Python. This inventory is not a complete redistribution legal audit, a signed release, or an automatic image-update protocol. Linux build package resolution is recorded, not claimed bit-for-bit reproducible across future repository changes.

Carry forward actual Windows Docker/NTFS/SQLite/transport/dependency-tag validation, native-human dialogs, whole-host-job/close-during-privileged-install, work-only STARK and clean-machine gates separately. A Windows payload launched on a runner with a synthetic/missing engine cannot close those gates. Existing M31 no-follow target/journal/phase/poison/cleanup controls remain required; packaging changes cannot replace effect authority with a private checksum claim.
